Space play/pause   R restart   C clean view. One frame is captured per frame interval and the clock advances exactly one step per captured frame, so the file is the length you asked for. The Format button lists what this browser can actually encode, best first, and the grey text beside it is the exact codec string it will use. MKV and MP4 both hold H.264, so they remux to MP4 losslessly; WebM has to be re-encoded:
ffmpeg -i Recombination_<pass>.mkv -c copy Recombination.mp4  (from MKV, instant)
ffmpeg -i Recombination_<pass>.webm -c:v libx264 -crf 16 -pix_fmt yuv420p -r 30 Recombination.mp4  (from WebM)
An MP4 written by the browser is fragmented; if Camtasia refuses it, ffmpeg -i in.mp4 -c copy out.mp4 rewrites the index without re-encoding.

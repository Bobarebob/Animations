WebM → MP4

Converts canvas recordings to H.264 MP4 that Camtasia imports without re-encoding. Runs entirely in your browser — nothing is uploaded.

Choose .webm files or drop them here — several at once is fine

Serve it, don't double-click it. ffmpeg.wasm needs a real origin, so open this page over http(s) — put it next to your animations on GitHub Pages, or run python -m http.server in its folder and visit http://localhost:8000/WebmToMp4.html. Opening it as a file:// path will fail to load the encoder.

First conversion is slow. The encoder core (~32 MB) downloads once, then caches.

Every output uses -pix_fmt yuv420p, which is the setting Camtasia and QuickTime require. Without it they often reject the file even though it plays fine in a browser.
